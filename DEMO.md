# 42-second demo

## Shot list

1. **0:00–0:04 — Hook.** Open Mission Control over the live universe. “Your projects are worlds.”
2. **0:04–0:09 — Real source.** Change to a curated, public-safe project root. Show Filesystem and Codex as Live.
3. **0:09–0:16 — Cause and effect.** Create or rename one folder in a visible Finder window. Keep the action and the arriving planet in one uncut shot.
4. **0:16–0:21 — Real object.** Create a file and open its new asteroid, or double-click the new planet to inspect its actual contents.
5. **0:21–0:35 — The fleet.** Start a real Codex task inside a displayed project. The primary ship launches; as the agent changes working directory or touches a recognized file target, the ship retargets within that project's local space. Delegated agents appear as additional named probes. Keep the Mission Control live count visible briefly, then show the ships.
6. **0:35–0:39 — Completion.** A real write updates the world. A ship turns green only after genuine task completion.
7. **0:39–0:42 — End card.** “Universe Screen — rebuilt from my earlier prototype with GPT-5.6 Sol Ultra. Native macOS · Metal · live filesystem · live Codex.”

Suggested voiceover:

> I built an early Mac prototype where folders became planets. Sol Ultra helped me rebuild it in native Metal. This planet appeared because I created that real folder—and these ships are live Codex agents working in the matching repositories.

## Before recording

- Select a curated root containing only public-safe folder and file basenames.
- Keep Privacy Mode on; remember that world labels remain real basenames.
- Verify the dashboard shows both integrations as Live.
- Use the measured FPS shown under Advanced; do not claim a higher number.
- Start Codex from the exact project directory so its ship maps to the correct planet.
- Use two visibly different file targets inside that project so the retargeting flight is unambiguous.
- Call the star network-reactive, not a bandwidth meter.
- Call Gamified Mode an overlay above Finder icons, not a Finder replacement.
- Never label a ship with a model name unless the captured metadata verifies it.
